# 다시집 제품 요구사항

길에서 만난 보호자 없는 반려동물을 사진 한 장으로 30초 안에 제보하고, AI가 외형 정보를 구조화해 보호자와 지역사회에 안전하게 연결하는 모바일 웹앱입니다.

| 항목 | 값 |
|---|---|
| 서비스명 | 다시집 |
| 코드명 | REBIRTH |
| 저장소 | `b-meal/rebirth` |
| 제품 유형 | 모바일 우선 웹앱, 설치·회원가입 없음 |
| 대회 | Wanted AI Championship 2026 |
| 참가 접수 마감 | 2026-09-18 23:59:59 KST |
| 과제 제출 마감 | 2026-09-20 23:59:59 KST |

## 문제

한국에서 보호자 없는 개나 고양이를 발견하면 제보 경로가 다섯 갈래로 흩어집니다.

| 경로 | 한계 |
|---|---|
| 포인핸드 | 앱 설치와 가입이 필요하고 보호소 공고 중심 |
| 당근 동네생활 | 자유 형식 게시글이라 위치·시간·외형이 누락 |
| 지역 커뮤니티, 맘카페 | 채널마다 중복 게시가 필요 |
| SNS | 이미지와 문구를 따로 제작 |
| 공공 신고 | 관할 지자체와 신고 번호를 직접 탐색 |

정보가 구조화되지 않아 목격 정보가 있어도 보호자에게 제때 닿지 않습니다. 2024년 구조된 유실·유기동물 106,824마리 중 소유자에게 반환된 비율은 11.4%입니다.

## 제품 언어 원칙

현장에서 해당 동물이 유기됐는지, 길을 잃었는지, 동네고양이인지 단정할 수 없습니다. 아래 원칙을 UI 문구와 제출 자료 전체에 적용합니다.

| 금지 표현 | 사용 표현 |
|---|---|
| 유기동물 판별 | 발견동물 제보·연결 |
| 말티즈 | 흰색 소형견, 말티즈 계열 추정 |
| 동일 개체 확정 | 확인할 후보 |
| AI 진단 | AI 초안, 사용자 수정 가능 |

AI의 역할은 품종 정답을 맞히는 것이 아니라 제보 내용을 빠르고 일관되게 구조화하는 것입니다.

## 대상 사용자

| 사용자 | 핵심 문제 |
|---|---|
| 발견자 | 어디에 신고할지 모르고, 외형을 어떻게 적을지 모르고, 앱 설치에서 이탈 |
| 실종 보호자 | 여러 앱과 SNS를 반복 확인하고, 제보가 비구조화라 비교가 어려움 |
| 보호소·동물병원·지자체 | 사진·위치·시간이 누락된 신고를 받고 중복 제보를 찾기 어려움 |

## 경쟁 서비스와 차별점

| 서비스 | 강점 | 다시집이 채우는 빈틈 |
|---|---|---|
| 포인핸드 | 보호소 공고, 입양 데이터 | 설치 없이 30초 안에 끝내는 발견 순간 UX |
| 당근 | 하이퍼로컬 도달력 | 구조화된 제보와 실종 신고 자동 매칭 |
| 펫나우 | AI 생체인식 매칭 | 무설치 제보, 위치 안전 처리, 공공 신고를 한 흐름으로 연결 |

차별화 문장은 다음과 같습니다.

> 포인핸드가 보호소와 입양에 강하고, 당근이 동네 확산에 강하고, 펫나우가 생체인식에 강하다면, 다시집은 발견 순간의 사진과 위치를 30초 안에 구조화해 보호자·지역사회·공공 신고체계로 전달하는 데 집중합니다.

## 핵심 사용자 여정

1. 회원가입 없이 웹앱 접속
2. 카메라 촬영 또는 앨범 업로드
3. 현재 위치 수집 또는 목격 장소 직접 입력
4. AI가 동물 종류, 추정 외형, 털색, 크기, 상태 초안 생성
5. 사용자가 잘못된 항목 수정
6. 상태 태그 선택
7. 제보 저장 후 고유 URL 발급
8. 보호자가 실종 신고를 등록하면 후보 목격 제보를 근거와 함께 확인
9. 모바일 공유창으로 인스타그램, Threads, 카카오톡 확산

## P0 범위

제출일까지 반드시 완료합니다.

| ID | 항목 | 완료 조건 |
|---|---|---|
| P0-1 | 제보 생성 파이프라인 | 사진 업로드, 위치 수집, 4단계 폼, DB·스토리지 저장 |
| P0-2 | AI 비전 분석 | 서로 다른 사진에서 서로 다른 결과, 비동물 사진 재촬영 안내, 실패 시 수동 입력 |
| P0-3 | 위치·개인정보 안전 | 정확 좌표를 공개 응답과 공유 카드에서 제외, 역지오코딩, 권한 거부 폴백 |
| P0-4 | 실종 신고와 설명 가능한 매칭 | 실종 신고 1건 등록, 후보 상위 노출, 점수 구성과 추천 이유 표시 |
| P0-5 | 제보 상세와 공유 | 고유 URL, OG 메타, 1080x1350 카드, Web Share API |
| P0-6 | 운영 안전 | 서버 측 검증, 레이트리밋, 신고·숨김 필드, 개인정보처리방침 |
| P0-7 | 측정과 사용자 검증 | AI 평가 20장, 사용자 테스트 5~10명 결과표 |

## P1 범위

P0가 안정된 이후에만 진행합니다.

- 국가동물보호정보시스템 API 연동
- 지역 반경 알림
- 보호자와 발견자의 익명 연락
- 운영자 검수 대시보드
- 중복 목격 제보 병합
- 이미지 임베딩 유사도 고도화
- PWA 설치 경험 개선

## AI 분석 출력 스키마

`POST /api/analyze`의 응답은 아래 필드를 JSON schema로 강제합니다.

| 필드 | 타입 | 설명 |
|---|---|---|
| `animalType` | `dog` \| `cat` \| `other` \| `unknown` | 동물 종류 |
| `appearance` | string | 외형 요약, 품종 단정 금지 |
| `color` | string[] | 털색 태그 |
| `size` | `small` \| `medium` \| `large` \| `unknown` | 추정 크기 |
| `condition` | string | 관찰 가능한 상태 |
| `collarOrHarness` | boolean \| null | 목줄·하네스 착용 |
| `visibleInjury` | boolean \| null | 눈에 보이는 부상 |
| `earTip` | boolean \| null | 귀 끝 절단, 중성화 표식 |
| `confidence` | number | 0~1 |
| `warnings` | string[] | 사진 품질, 비동물, 재촬영 안내 |

## 안전 및 법적 원칙

- 동물을 무리하게 포획하라고 지시하지 않습니다.
- 다치거나 도로 위에 있는 동물은 1577-0954 또는 관할 지자체 신고를 안내합니다.
- 길고양이는 귀컷, 부상, 어린 개체 여부에 따라 안내를 구분합니다.
- 정확한 위치를 전체 공개하지 않습니다.
- 연락처를 공개 필드로 저장하지 않습니다.
- AI 결과를 의료 진단이나 개체 동일성 확정으로 표현하지 않습니다.
