# 결정 기록

프로젝트 방향을 바꾸는 결정만 기록합니다. 각 항목은 결정일, 선택지, 근거, 되돌리는 조건을 포함합니다.

## D-001 서비스명은 다시집, 코드명은 REBIRTH

- 결정일: 2026-09-08
- 선택지: 다시집 유지, REBIRTH를 서비스명으로 승격, 새 이름 공모
- 결정: 사용자에게 보이는 이름은 다시집, 저장소와 내부 문서는 REBIRTH
- 근거: 한국 일반 사용자 대상 서비스라 한글명이 직관적이며, 영문 코드명은 저장소·배포 식별자로 충분합니다.

## D-002 백지에서 Next.js로 재구축

- 결정일: 2026-09-08
- 선택지: 기존 vinext 구현 이식, Next.js로 재구축
- 결정: Next.js 15 App Router로 새로 작성하고 기존 구현은 UI 참고 자료로만 사용
- 근거: 기존 구현이 쓰던 `vinext 1.0.0-beta.5`는 베타 릴리스라 해커톤 기간 중 지연 위험이 있습니다. Next.js는 팀 3인이 모두 다룰 수 있고 Vercel Preview 배포로 PR마다 확인 가능한 URL이 나옵니다.
- 되돌리는 조건: 09-10까지 제보 플로우가 완주되지 않으면 기존 구현 이식으로 전환합니다.

## D-003 인프라는 Vercel과 Supabase

- 결정일: 2026-09-08
- 선택지: Vercel + Supabase, Cloudflare Workers + D1 + R2, Vercel + Neon + Blob
- 결정: Vercel 배포, Supabase Postgres·Storage
- 근거: 매칭 기능이 반경 검색과 거리 정렬을 요구합니다. PostGIS가 이를 SQL로 해결하고, pgvector로 이미지 임베딩 확장 여지도 같은 데이터베이스에 둘 수 있습니다. D1은 SQLite 기반이라 지리 연산을 직접 구현해야 합니다.
- 되돌리는 조건: Supabase 무료 한도로 시연이 불안정하면 유료 티어로 전환합니다. 인프라 자체는 바꾸지 않습니다.

## D-004 비전 모델은 claude-sonnet-5

- 결정일: 2026-09-08
- 선택지: `claude-sonnet-5`, `claude-haiku-4-5`, `claude-opus-5`, 타사 비전 모델
- 결정: 기본 `claude-sonnet-5`, 비용 초과 시 `claude-haiku-4-5`로 전환
- 근거: 아래 표 기준으로 제보 1건당 약 11원이며 1,000건을 분석해도 1.1만 원입니다. 구조화 출력으로 JSON schema를 강제할 수 있고, 개발 도구가 Claude Code라 제출 자료의 AI 도구 사용 내역이 일관됩니다.

| 모델 | 입력 $/1M | 출력 $/1M | 제보 1건 추정 |
|---|---|---|---|
| `claude-sonnet-5` | $2.00 | $10.00 | 약 11원 |
| `claude-haiku-4-5` | $1.00 | $5.00 | 약 5원 |
| `claude-opus-5` | $5.00 | $25.00 | 약 27원 |

추정 기준은 이미지 1장 약 1,400 토큰, 프롬프트 약 500 토큰, 출력 약 400 토큰, 환율 1,400원입니다.

- 비용 상한: 해커톤 기간 전체 5만 원. 3만 원 도달 시 Haiku 4.5로 전환하고 동일 사진 재분석을 차단합니다.

## D-005 저장소는 public, main과 develop을 보호

- 결정일: 2026-09-08
- 선택지: public + 브랜치 보호, private + GitHub Team 결제, private + 보호 없음
- 결정: `b-meal/rebirth`를 public으로 생성하고 두 브랜치에 보호 규칙 적용
- 근거: b-meal 조직은 Free 플랜이라 private 저장소에는 보호 규칙을 걸 수 없습니다. 오픈소스 공개는 심사에서 실현 가능성 근거로도 쓸 수 있습니다.
- 전제: 모든 시크릿은 Vercel 환경변수로만 관리하며 저장소에 어떤 키도 커밋하지 않습니다.

## D-006 매칭 v1은 이미지 임베딩 없이 시작

- 결정일: 2026-09-08
- 선택지: 처음부터 임베딩 포함, 규칙 기반 점수만
